# Humanoid Dodgeball Color Scheme

The website retains the original template palette. Edit these variables in `style.css` to change the theme.

| Variable | Color | Use |
| --- | --- | --- |
| `--honey-bronze` | `#d4940a` | Primary accent |
| `--hyper-magenta` | `#9333ea` | Secondary accent |
| `--neon-violet` | `#a855f7` | Gradient transitions |
| `--cool-horizon` | `#3b82f6` | Cool accent |
| `--blue-energy` | `#2563eb` | Deep blue accent |
| `--bg-deep` | `#fafafa` | Page background |
| `--bg-surface` | `#ffffff` | Cards and header |
| `--text-primary` | `#1a1a1a` | Headings and main text |
| `--text-secondary` | `#4a4a4a` | Supporting text |
| `--text-muted` | `#7a7a7a` | Captions |
